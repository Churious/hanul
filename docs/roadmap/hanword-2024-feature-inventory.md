# 한글 2024 기능 인벤토리

조사 기준: Windows에 설치된 한글 2024, 공식 온라인 도움말의 HOffice 2024 메뉴 분류, Hanul 저장소의 비교 가능한 기능 조사. 각 ID는 격차 분석과 로드맵에서 같은 단위로 사용한다. 총 **132개 기능 조사 단위**다. 한 단위 안의 쉼표 항목은 같은 명령군의 옵션이며, 별도의 미확인 기능을 완료로 세지 않는다.

## 증거 등급

- **GUI-메뉴**: Computer Use로 해당 한글 2024 메뉴/리본에 명령명이 표시되는 것을 직접 확인. 명령의 전체 동작을 실행했다는 뜻은 아니다.
- **GUI-리본**: 선택 문맥에서 리본 컨트롤을 직접 확인. 표·개체 조작의 전체 과정 검증과는 구분한다.
- **GUI-대화상자**: 대화상자를 열고 보이는 탭/필드를 직접 관찰.
- **공식 도움말**: Hancom HOffice 2024 온라인 도움말의 기능 설명. 이 작업에서 GUI로 동작을 실행하지 않은 하위 기능은 여기에 해당한다.
- **소스/테스트**: Hanul의 소스 또는 자동화 테스트에서 확인된 구현 단서. 한글 2024 기능의 증거로 쓰지 않는다.
- **미확인**: 직접 조작과 신뢰 가능한 도움말 설명이 부족하다. 추정은 인벤토리 항목에 사실처럼 적지 않는다.

공식 도움말은 메뉴 트리를 포괄적으로 열거하지만, 모든 항목의 버전별 동작과 모든 설정 값이 GUI에서 재현됐다는 뜻은 아니다. 메뉴의 최상위 구조와 일부 대표 리본 명령은 직접 확인했고, 개별 대화상자 및 메뉴 항목 대부분은 공식 도움말로 보완했다. 조사 과정은 [research-notes.md](research-notes.md)에 기록했다.

## 조사 공백

- UIA로 확인한 것은 실제 설치 앱의 상단 메뉴와 대표 편집 리본이다. 탭별 모든 하위 탭, 도구 모음 버튼, 선택별 컨텍스트 메뉴를 모두 펼쳐 본 결과는 아니다.
- 단축키는 도움말 또는 화면 레이블의 증거만 있다. 전체 기본 키맵을 실제로 눌러 확인한 것은 아니다.
- 표, 그림, 글상자, 보안, 검토, 맞춤법, 차례의 상세 대화상자 조작과 저장 결과는 별도 시나리오로 검증해야 한다.
- 한글 2024의 기능 목록은 Hanul 지원을 의미하지 않는다. 현재 Hanul 상태는 [feature-gap-analysis.md](feature-gap-analysis.md)에서 독립 엔진과 RHWP 호환 경로를 나눠 확인한다.
