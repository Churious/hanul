# Roadmap

## M1 — 문서 엔진과 데스크톱 바탕

- [x] 개발 환경과 RHWP API/라이선스 조사
- [x] RHWP Wasm 문서 모델 어댑터와 Tauri 2 데스크톱 셸
- [x] HWP/HWPX 열기, 페이지 조판 렌더링, HWP 저장 손실 보고
- [x] 새 HWP 문서 생성

## M2 — 직접 편집

- [x] 페이지 좌표와 RHWP 문서 커서 연결
- [x] 본문 및 표 셀 텍스트 입력, 삭제, 문단 나누기/병합
- [x] 한글 입력을 위한 IME 조합 브리지
- [x] 편집 내용 undo/redo와 소스 형식 저장
- [x] HWP 신규 문서 편집, Undo/Redo, 저장·재열기 검증
- [ ] 기존 HWP와 HWPX 실문서에서 편집·재열기 검증
- [ ] Windows IME 조합과 커서 이동을 데스크톱에서 확인

## M3 — 기본 편집 리본

- [x] 드래그 텍스트 선택 및 문서 모델 선택 영역 표시
- [x] 글꼴, 글자 크기, 굵게, 기울임, 밑줄, 문단 정렬
- [x] 표 생성, 셀 이동, 표 셀 텍스트 서식
- [x] 텍스트 복사, 잘라내기, 붙여넣기
- [x] 문서 찾기/바꾸기 및 모두 바꾸기의 단일 Undo 작업
- [x] 표 행 추가와 셀 병합의 스냅샷 Undo/Redo
- [ ] 선택 범위가 여러 문단에 걸친 편집과 서식
- [ ] 모든 리본 명령마다 undo/redo와 HWP/HWPX 왕복 검증
- [ ] 눈금자 조절과 문단 들여쓰기/탭 편집

## M4 — 페이지와 표 편집

- [ ] 행/열 추가 및 삭제, 셀 병합/분할, 셀 크기 조절 (일부 명령만 연결·검증)
- [ ] 이미지 삽입·크기 변경과 기존 이미지 보존
- [ ] 페이지 여백, 용지 크기, 쪽 나눔, 머리말/꼬리말
- [ ] 인쇄와 PDF 내보내기

## M5 — 문서 호환성과 고급 기능

- [ ] 글상자, 필드, 도형, 수식, 각주/미주 편집
- [ ] 스타일, 목록, 다단, 문단 테두리·배경
- [ ] 복합 문서 코퍼스에서 내용 보존과 왕복 조판 비교

## M6 — 배포와 안정화

- [ ] 성능, 접근성, 오류 복구 및 자동 저장
- [ ] Windows 설치 프로그램과 Linux 패키지 빌드·실행 확인
- [ ] 파일 열기/편집/저장 사용자 흐름 검증

체크 표시는 코드에 연결된 범위를 나타냅니다. 배포 가능한 기능으로 판단하려면 문서 형식별 GUI 사용과 저장 왕복 증거가 필요하며, 현재 상태는 [호환성 표](compatibility/matrix.md)에 구분해 기록합니다.
